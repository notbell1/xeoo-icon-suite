## ⚡ What Makes Xeoo Icons Different?

> **"Cybernetic Precision for Every File, Folder, and Language in Your Tree."**

Designed as the dedicated icon companion to the **[Xeoo Theme Suite](https://github.com/notbell1/xeoo-theme-suite)**, **Xeoo Icon Theme** replaces generic, cluttered icon sets with a unified, high-contrast visual system:

* 📐 **Cybernetic Geometry & Chamfers**: Every glyph is drafted on a strict **32 × 32 px artboard** with characteristic 45° chamfers, balanced line weights, and structural corner accents.
* 👁️ **16 × 16 px Explorer Legibility**: Engineered specifically for VS Code's standard 16 px tree view. High-contrast silhouettes and distinct outer profiles guarantee immediate recognizability even at glance speeds.
* 🌓 **Universal Dual-Mode Contrast**: Calibrated with luminous neon boundaries and balanced core fills that pop cleanly against deep obsidian dark themes as well as high-key light themes.
* 🛡️ **Zero Runtime Overhead & 100% Native**: Zero npm dependencies, zero telemetry, and zero script injections. Built directly into pure VS Code declarative icon theme JSON.

## 🚀 Installation Guide

### 🌟 Method 1: Install VSIX via VS Code UI (Recommended)

```text
[ Open VS Code ] ➔ [ Extensions (Ctrl+Shift+X) ] ➔ [ Click "..." menu (top right) ] ➔ [ Install from VSIX... ]
```

<details open>
<summary><b>👉 Step-by-Step Instructions</b></summary>
<br/>

1. Open **Visual Studio Code**.
2. Open the Extensions sidebar with **`Ctrl + Shift + X`** (or **`Cmd + Shift + X`** on macOS).
3. Click the **three dots (`...`)** (*Views and More Actions*) in the top-right corner of the Extensions view.
4. Select **`Install from VSIX...`**.
5. Select the **`xeoo-icon-theme-0.1.0.vsix`** file located in this repository folder and click **Install**.
6. **Done! 🎉** Activate it via the theme picker.

> 💡 **Quick Terminal Install:**
> ```bash
> code --install-extension xeoo-icon-theme-0.1.0.vsix
> ```

</details>

<br/>

### 📂 Method 2: Manual Directory Copy

<details>
<summary><b>👉 Step-by-Step Manual Copy</b></summary>
<br/>

Copy this entire project folder into your VS Code extensions directory:

* 🪟 **Windows**: `%USERPROFILE%\.vscode\extensions\xeoo-icon-theme`
* 🍎 **macOS**: `~/.vscode/extensions/xeoo-icon-theme`
* 🐧 **Linux**: `~/.vscode/extensions/xeoo-icon-theme`

Restart VS Code after copying.

</details>

<br/>

### 🧪 Method 3: Developer Host Mode (F5)

<details>
<summary><b>👉 Development Host Launch</b></summary>
<br/>

1. Open this repository folder in VS Code.
2. Press **`F5`** to launch an **Extension Development Host** window.
3. Open any workspace or test fixtures folder to inspect the icon suite live!

</details>

## 🛠️ Developer Scripts & Build Pipeline

The entire build and packaging pipeline is self-contained and runs on vanilla Node.js:

```bash
# 🔨 Compile modular definitions into themes/xeoo-icon-theme.json
npm run build

# 🧪 Run automated SVG validation and resolution precedence suite (96 tests)
npm test

# 📦 Package standalone .vsix installer (zero external dependencies)
npm run package
```

### Precedence Resolution Architecture

The compiler and resolver enforce strict precedence to ensure specialized icons always win over general fallbacks:

```text
Priority 1: Exact Filenames (e.g., tailwind.config.js, package.json, phpunit.xml)
    ↓
Priority 2: Multi-part Extensions (e.g., .blade.php, .component.ts, .test.tsx)
    ↓
Priority 3: Standard File Extensions (e.g., .php, .ts, .js, .py, .rs)
    ↓
Priority 4: VS Code Language IDs (e.g., php, typescript, python)
    ↓
Priority 5: Default Fallback Carrier (file.svg / folder.svg)
```
